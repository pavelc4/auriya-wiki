# Auriya Wiki

Official technical documentation for the [Auriya](https://github.com/pavelc4/auriya) Magisk/KernelSU/APatch module — an automated background game optimization daemon and frame rate management framework for Android.

Live site: [auriya.pages.dev](https://auriya.pages.dev/)

---


## Quick Start

### Prerequisites

- [Bun](https://bun.sh) (v1.1 or higher)

### Installation

```bash
# Clone repository
git clone https://github.com/pavelc4/auriya-wiki.git
cd auriya-wiki

# Install dependencies
bun install
```

### Local Development

```bash
bun run dev
```

Starts the local development server at `http://localhost:3000`.

### Production Build

```bash
bun run build
```

Generates optimized static HTML in the `dist/` directory.

### Preview Production Build

```bash
bun run preview
```
