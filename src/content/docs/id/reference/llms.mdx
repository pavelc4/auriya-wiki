## Panduan Integrasi

### 1. Pada AI IDE & Coding Assistant

Tambahkan URL dokumentasi Auriya sebagai sumber referensi (*custom doc source*) pada editor AI Anda (Cursor, Windsurf, Claude Code, Antigravity, GitHub Copilot):

<Tabs>
  <TabItem label="URL Indeks (Disarankan)">

```text
https://auriya.pages.dev/llms.txt
```

  </TabItem>
  <TabItem label="File Konteks Lengkap">

```text
https://auriya.pages.dev/llms-full.txt
```

  </TabItem>
</Tabs>

### 2. Pengambilan Data via Terminal / cURL

Unduh atau salurkan (*pipe*) konteks dokumentasi langsung ke tool LLM baris perintah:

<Tabs>
  <TabItem label="Unduh ke File">

```bash
# Unduh seluruh dokumentasi untuk prompt offline
curl -sSL https://auriya.pages.dev/llms-full.txt -o auriya_docs.md
```

  </TabItem>
  <TabItem label="Pipe ke LLM CLI">

```bash
# Salurkan konteks ringkas langsung ke CLI LLM
curl -sSL https://auriya.pages.dev/llms-small.txt | llm "Jelaskan penjadwalan dinamis FAS Auriya"
```

  </TabItem>
</Tabs>

## Pembaruan Otomatis

File-file ini dibuat secara otomatis pada setiap siklus build dan deployment menggunakan `starlight-llms-txt`. Setiap pembaruan panduan konfigurasi, protokol IPC, atau arsitektur akan langsung tersinkronisasi secara real-time.
